# Windows 分发与验证记录

日期：**2026-10-08**；版本：**0.2.0**；实施分支：`feature/complete`。目标为完成可对外分享的本机练习包，最终人工验收按用户要求另留。基本交易与训练范围沿用 [产品与设计](01-product-and-design.md)，业务参数和保存政策只在 [数据与交易](03-data-and-trading.md) 维护。

## 实际交付形态

`npm run package:windows` 执行类型检查和生产构建，再生成 `release/FX-practice-room-0.2.0-win-x64.zip`、同名目录及外部 `.sha256`。使用者完整解压并双击 `启动.cmd`，无需安装 Node.js、npm 或开发依赖。服务严格绑定 `http://127.0.0.1:4173`，占用时拒绝，不自动换端口；运行只读本地应用文件，账户和行情仍存于浏览器 IndexedDB。

包内包含界面、字体、原创图标、生成 CSV 模板、空历史样本清单、官方 Node.js 24.21.0 Windows x64 可执行文件及其完整 LICENSE、原生启动服务、中文说明和逐文件发行清单。应用运行依赖的十份许可/NOTICE 原样保留。发行只复制明确允许的文件，私用真实价格及元信息、个人记录、开发依赖和源代码目录不进入包；未知构建文件与链接会拒绝打包，原文件保留。私用数据仍留在本机，不为分发删除。

固定运行时来自 Node.js 官方发行目录，下载归档及可执行文件均核对官方 SHA-256；完整许可取自同一核验后的归档。首次下载属于开发打包准备，后续完整缓存可离线使用；版本不随“最新”变化。依据见 [工程研究 E20](../knowledge/02-web-engineering.md#e20官方-nodejs-运行时与再分发文件)。

`check:release` 同时核对目录、外部 ZIP 指纹、实际 ZIP 解压全部内容与清单。重复打包仅替换核验过的既有生成产物，存在额外或被改动文件时拒绝。启动批处理使用 ASCII 命令，中文说明由 UTF-8 Node 输出；避免 Windows CMD 对 UTF-8/LF 中文命令的截断。所有源码和说明文本采用 UTF-8 无 BOM、LF。

## 存储收尾

- 保存失败保持暂停、原库、未保存候选与事前计划。清理入口可明确删除无关旧练习及未引用源，事务核对当前指针和激活基准；当前持久练习、未保存候选及其源受保护，陈旧窗口不能借清理删除另一窗口当前状态。释放空间后重试同一候选，不再次成交。
- 可恢复故障备份包含本场失败候选、所需完整行情、待提交计划和训练对照，沿用正常恢复格式；在新库或正常窗口中追加独立副本，原记录保留。原始快照只用于诊断，不伪装成可恢复备份；坏前缀、坏摘要、坏观察及超预算明确拒绝，不挂起或删除原数据。
- 完整备份取消与字节预算重复的 50 数据集、1,000 会话等数量门槛，增加逐练习导出。逐练习头、源、归档和元数据通过单一 readonly 事务捕获，不能混入后来窗口的更新。输入及导出字节预算、逐场备份清理策略与尚未提供的分片能力见业务文档，不承诺无限存储。

## 保留的人工待办与范围

实际物理断网、用户默认浏览器的交互打开体验、讲述人/NVDA 和本人连续练习体验未执行，不描述为通过。隔离代理环境的外网不可达、自动浏览器、AX 树和命令启动不能代替这些人工验收。

面向 Windows 10/11 x64 的 Chrome/Edge；记录当前真实系统与浏览器版本，不推断另一 Windows 版本或其他内核已经实测。便携包没有安装器、签名安装程序、自动更新或跨平台承诺；升级以外部备份、关闭旧服务及固定浏览器地址恢复为准。GitHub Actions 尚未配置，验收来自本机命令及隔离测试。超大单场备份、真实物理配额耗尽与教学效果仍按证据边界说明。

本任务完成可分发产物与仓库同步，不自动公开上传个人行情，也不将本地产物描述为已经发布的 GitHub Release。
