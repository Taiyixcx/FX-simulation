## 定位与使用流程

FX 练习室是供本人在本机使用的外汇练习站。通过生成行情和真实历史报价，练习观察走势、判断方向、开仓、平仓和复盘。界面面向新手，优先保证图表清楚、操作直接和交易结果容易理解。

主要流程为“选择行情与品种 → 查看报价 → 输入金额 → 买涨或买跌 → 推进行情 → 平仓并复盘”。事前理由、退出计划和风险预览均可跳过；观察而不交易也可记录。模拟练习持续生成并保存种子和进度，新练习采用独立资金及不同随机种子。历史练习支持开始时间和此前观察，末尾自动暂停。刷新和打开旧会话均恢复原账户、来源与进度并暂停。

真实历史报价与训练成交模型分别标识。分钟回放呈现已经完成的分钟数据，不声称还原逐笔执行。具体默认参数、交易计算和会话规则统一见 [数据与交易](03-data-and-trading.md)，实施顺序和检查场景见 [路线与验收](04-roadmap-and-acceptance.md)。

工作台最大宽度 1520px，桌面外围间距及各区域左右内边距 24px，下单区宽 336px，其余主要空间留给图表。品牌栏、浅薄荷账户指标横栏、主图与交易侧栏、成交区共用边距与对齐线，组成连续工作台。整体容器圆角 10px、无悬浮阴影，内部以细分隔线连接；1440×900 首屏容纳账户、报价、图表、回放及持仓平仓。品牌栏提供成交记录锚点和固定位置的本机保存状态。权益、Bid 和持仓盈亏有明确主次，数字与 USD 单位分级，不重复展示整组报价或完整行情时间。

宽度不超过 1100px 时，图表全宽，下方下单与持仓并排；不超过 600px 时改为单列，左右间距 16px。账户概要按实际容器宽度与 rem 重排：空间不足时权益占首行、其他指标两列，极窄或文字放大时单列，资金数字不会因平均分栏而拆行。行情与回放控件按功能自然换行，整页不横向溢出。图表下方提供“去下单 / 查看持仓与平仓”入口，主动点击后定位并聚焦金额或持仓标题；行情推进不抢焦点。

成交记录采用六列语义表格：方向、金额、开仓信息、平仓信息、结算盈亏、原因，开平仓的价格与时间分两行。当前会话已平仓记录每页 20 条，可翻页查看全部记录；分页不删除历史成交。宽度不超过 700px 时切换为可展开列表，摘要显示方向、名义金额和盈亏，详情保留所有报价、时间及原因。平仓入口保持在持仓区。

行情工具栏以品种标识、货币对和模拟状态说明当前内容，折线/K 线使用分段控件。“新练习情景”提供常规练习和事件练习，选择后点击“新练习”才启动；当前情景单独标明，避免将待选情景误认为当前行情设置。最近已发生模拟事件显示时间、简短标签和按需详情；计划事件只显示时间、类型说明和预期，不透露实际结果。金额输入带 USD 后缀，快捷金额显示选中态；买涨与买跌使用浅语义底色，显示方向及各自成交报价。持仓区以盈亏及细语义边线为重点，开仓价、资金占用和开仓时间使用紧凑键值排版；墨色平仓按钮同时显示实际 Bid/Ask 平仓报价。已有持仓时明确说明禁用下单的原因。

切换品种或“新练习”先暂停并保存旧练习，创建独立资金和不同随机序列；情景只在新会话创建时确定。旧会话在“练习与完整备份”中分页展示，可恢复账户、持仓、来源和进度并暂停；未记录的实际保存时间不冒充行情日期。损坏条目标明原因，读取失败不覆盖当前会话。

主图默认显示最近窗口；点击成交的“复盘 / 备注”读取开仓附近已发生行情，也可单独定位平仓。图表标明“复盘观察”，进入时聚焦图表，返回后恢复原入口焦点。复盘不回滚账户、不重新结算；交易区明确仍按当前末根报价成交。模拟归档和历史前缀均按有界窗口读取，缺块或无法定位时保留原数据并提示错误。

“历史数据”默认收起，通过原生展开控件支持鼠标和键盘。导入与本机样本载入只新增数据集；选定 UTC+8 开始时间、此前观察数量，再启动独立资金的历史练习，旧记录保留。此前分钟只作预热观察，不参与成交。文件与来源输入按原有分组排列，导入显示校验阶段、进度、取消及逐行错误；保存完成才显示成功。历史品种由数据集固定，来源真实性和当前行 Ask 来源分别说明；缺口按现有下一条报价推进，不补假分钟。窄屏改为单列。

“风险预览与事前计划”及持仓风险说明默认收起。预览可选择方向和可平仓一侧的假设报价，显示数量、每 pip 金额、当前平仓及假设结果。首次计划随开仓保存，后续修订与实际退出备注在本笔编辑；并发版本冲突保留草稿，用户明确读取保存版本后才替换输入。文本长度与报价规则统一见 [数据与交易](03-data-and-trading.md)。

统计按需读取当前练习的完整已推进行情，显示笔数、净已结算盈亏、平均盈利/亏损和结果分布；余额与权益回撤分别展示。曲线说明绘图取样与完整统计的区别；单笔最大浮盈/浮亏标记为完成分钟可平仓报价采样，不推断分钟内或缺口内极值。没有对应样本时显示无样本，不把单笔盈利、胜率或前后变化评为能力成绩。

“练习与完整备份”提供正常导出、文件校验、恢复预览和用户选择。已有数据默认追加独立副本并保持当前练习；只有明确选择才打开恢复入口。导出校验可取消，提交阶段按界面状态处理，失败保留原库。保存失败时完整备份只含已提交数据，未保存现场另行导出故障快照。容量估算和持久存储申请同时说明其限制；删除非当前会话或未引用数据集需明确确认，不自动按容量清理。

## 视觉与图表

- 参考 [Bilibili 外汇模拟页](../knowledge/03-product-references.md#p01直接进入练习的轻量入口) 的薄荷与粉色搭配。背景 `#EFF5F2`、白色主区域、辅助表面 `#F3F8F5`、主文字 `#263A3B`、辅助文字 `#546F69`；分隔线 `#D9E8DF`，必要控件边界 `#6D8D82`。主色墨绿 `#2F765F` / 浅底 `#E7F3EC`，Bid 线 `#39866D` 配浅绿面积；盈利青绿 `#146747` / `#E4F3E9`，亏损深粉 `#9E304C` / `#FDEBF0`。买涨、买跌按钮分别用薄荷和粉色底，悬停与按下状态的文字也保持清楚。间距使用 4px 基数，控件圆角 6–8px。图标采用项目内 SVG。
- Inter 的英文及数字字体随应用打包，中文使用系统字体，使用实际打包的 400/500/600/700 字重，金额及报价使用等宽数字。桌面 Bid 40px、Ask 22px，手机分别为 34px、20px；权益 32px、其他账户数字 22px、持仓盈亏 30px。标题与方向强调使用 700，报价与金额使用 600，辅助标签使用 500。正文及操作标签 13–16px，次要时间与单位 12–13px；实际字号用 rem，极窄容器下权益字号调整为 1.75rem，避免金额拆行。Bid 尾部两位固定为主色，仅表达精度层次。
- 选择框保持原生选项与键盘操作，统一细边框、8px 圆角和本地 SVG 箭头；右侧保留至少 2.25rem 箭头空间。回放、情景与导入控件桌面最小高度 40px、手机 44px。历史模式的固定货币对保持清楚的文字，禁用操作仍提供对应说明。
- 金额带币种，报价使用一致精度；盈亏同时显示正负号、文字和颜色。方向按钮写“买涨（做多）”“买跌（做空）”。
- 控件颜色过渡 140ms，按下缩放 0.985、80ms；帮助淡入 140ms、最多位移 4px，交易反馈淡入 160ms。有限来源逐根推进的只读进度使用 100ms 宽度过渡，重置和恢复立即定位；持续练习只显示已推进根数。焦点使用 2px 实色墨绿环；`prefers-reduced-motion` 下取消过渡、位移及缩放。统一缓动为 `cubic-bezier(.2,.8,.2,1)`。报价、账户和图表即时更新，不滚动数字或持续闪烁。
- 默认打开暂停的模拟练习，默认 Bid 折线；切换 K 线时提供简短 OHLC 解释。货币对和交易数值默认值由 [数据与交易](03-data-and-trading.md) 维护。
- Apache ECharts 负责 Bid 折线与 K 线。十字线显示已可见的时间及价格；缩放和平移只能访问已经推进的数据，提供回到最新入口。报价、行情时间、图表和账户同步更新。
- 图表画布桌面高 350px、手机高 300px，均以 rem 定义。轴标签沿用正文缩放后的字体，时间标签数量按可用宽度减少。最新价只在最新帧处于观察范围时显示，使用右侧墨绿标签；按像素距离隐藏碰撞的普通价格刻度，观察旧区域时不展示范围外当前价。
- 开仓水平线使用实际成交报价，开平仓标记显示方向与成交价。入场标记文字可见时，水平线不重复显示同价文字；标记移出视窗或隐藏文字时，空间足够则恢复水平线标签。买涨的 Ask 入场线可以高于 Bid 曲线，不能为了贴合曲线改写成交价。
- 首根行情居中呈现，并说明初始状态，不填入虚构走势或未来占位行情。用户缩放或平移后的观察范围保持稳定；只有原来跟随最新时才自动移动。
- 页面不展示图表库品牌、版权段落、裸链接或技术页脚。依赖许可和 NOTICE 随源码及构建产物提供，不通过隐藏原图表库所要求的署名实现页面清理；选型依据见 [网页工程](../knowledge/02-web-engineering.md#图表与十进制计算)。

| 场景 | 页面行为 |
| --- | --- |
| 首次进入 | 加载完成后暂停行情并展示可跳过三步引导；引导解释操作，不强迫下单，完成或跳过状态保存在本机 |
| 无持仓或无成交 | 保持交易区和记录区的结构，使用简短状态、必要入口与轻量图标，避免大块教学文字 |
| 无历史样本 | 说明如何准备或导入数据，保留进入模拟练习的入口 |
| 交易金额无效或资金不足 | 在输入附近给出原因并保留输入；不能下单时提供可读说明 |
| 开仓后出现浮亏 | 在对应信息提示中解释买卖报价差形成点差成本，不暗示系统扣除了额外费用 |
| 开仓或平仓完成 | 保存成功后短反馈；开仓聚焦持仓标题，平仓聚焦金额，屏幕外的目标就近滚入；反馈中结算盈亏按实际正负着色，账户、记录和成交标记同步更新 |
| 行情数据结束 | 停止播放、标明结束，按最后可见报价提供平仓操作 |
| 持续生成与容量边界 | 本人可随时暂停；刷新不重置走势；保存失败或超出模拟时钟支持范围暂停并保留当前报价与已有记录 |
| 切换行情或恢复会话 | 按会话规则保存与装载，恢复后显示暂停状态 |
| 导入或恢复失败 | 显示具体原因；CSV 能定位时给出行号，保留原有数据 |
| 保存失败 | 显示“保存失败”并暂停推进与交易，提供重试、导出当前快照入口；由开平仓触发的写入失败将焦点移至持续错误区 |
| 多窗口保存冲突 | 拒绝陈旧写入，保留当前窗口快照；提示导出后重新打开最新练习 |
| 备注冲突或长度错误 | 显示本笔原因并保留草稿；失败焦点到错误提示，读取保存版需用户明确选择 |
| 删除资料 | 当前会话不可删除；非当前会话及未引用数据集按确认范围处理，取消保留原数据 |

保存状态保留在品牌栏固定位置。金额错误、保存失败和多窗口冲突持续显示具体原因及恢复入口，不收进帮助提示。普通下单与平仓无需增加重复确认。恢复、导入和保存中的按钮状态清楚，重复点击不产生重复成交或重复写入。

## 新手帮助与可访问性

报价、金额、点差、资金占用、练习情景和图表操作旁提供按需信息提示。模拟来源区分部分参数校准与仍属训练设定的机制，事件不保证下一根方向。提示支持键盘开启、Escape 关闭及返回焦点；点击外部或焦点离开时收起并保留新焦点。首用引导分三步解释报价、开仓成本和暂停平仓复盘，可随时跳过，不改变账户。

图表保留左右键平移、加减键缩放和 End 回到末根，增加上下键与可发现按钮逐根读数；等价行情表提供时间、OHLC、末组 Bid/Ask 和完成状态。播放不持续播报每根数字或抢焦点。M5/H1 只聚合已经发生的 M1，未完成组明确显示已有部分，买卖标记保留实际成交价格和时刻。

两组固定概念题分别反馈报价、风险上限和计划执行的理解，两组数字例题共用成交引擎；可以记录主动不交易的理由。对照入口保留首次练习，分别标记重练已见走势与本机未见片段；“本机未见”仅依据当前本机记录，不保证本人从未在别处看过，外来备份标记也不认证未见状态。学习效果仍待本人试用，不输出综合能力或实盘分数。

控件使用语义化按钮、标签和输入框，键盘可操作，并保留清楚可见的焦点。面板关闭后焦点回到开启入口；错误与保存结果使用可读状态提示。图表之外始终显示当前报价和持仓数字，不把交易必需信息只放在画布中。

文字和交互对比度参照 WCAG 2.2 定向检查；页面支持 200% 文字放大，320–1440px 的六种验收宽度无整页横向溢出。手机主要按钮、选择与帮助触控区至少 44px；键盘焦点与错误持续可见。工程资料见 [前端与存储知识](../knowledge/02-web-engineering.md)，实际验证及系统性无障碍检查的限制只记录到 [路线与验收](04-roadmap-and-acceptance.md)。
