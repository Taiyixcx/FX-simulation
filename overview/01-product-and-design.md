# 产品与设计

**2026-10-02 已接入新版工作台。** 本文维护实际布局与视觉参数；[整体美化方案](05-interface-redesign.md) 保留设计取舍，[官方设计研究](../knowledge/04-interface-design.md) 保存依据。[独立交互样稿](05-interface-preview.html) 是前期示意，不执行交易或保存。

## 定位与使用流程

FX 练习室是供本人在本机使用的外汇练习站。通过生成行情和真实历史报价，练习观察走势、判断方向、开仓、平仓和复盘。界面面向新手，优先保证图表清楚、操作直接和交易结果容易理解。

主要流程为“选择行情与品种 → 查看报价 → 输入金额 → 买涨或买跌 → 推进行情 → 平仓并查看记录”。P1 使用生成行情并保存同一练习的种子和进度，新练习使用新随机种子；真实历史回放安排在 P2。本地保存支持中断后继续。

真实历史报价与训练成交模型分别标识。分钟回放呈现已经完成的分钟数据，不声称还原逐笔执行。具体默认参数、交易计算和会话规则统一见 [数据与交易](03-data-and-trading.md)，实施顺序和检查场景见 [路线与验收](04-roadmap-and-acceptance.md)。

首版采用单页纯前端应用，无登录、后端、云同步、实时行情接口或真实下单。可调杠杆、多仓、挂单、止盈止损、滑点、隔夜费、完整经纪商保证金模型、技术指标和复杂报表，待实际使用后另行评估。排行榜、社区、贷款和挑战不纳入当前产品。

界面借鉴图表主导的回放操作、自动交易记录和操作旁教学，产品资料及取舍依据集中在 [同类作品研究](../knowledge/03-product-references.md)。

## P1 工作台布局

```text
┌─────────────────────────────────────────────────────────────┐
│ FX 练习室 / 交易工作台                    成交记录 保存状态 │
├─────────────────────────────────────────────────────────────┤
│ 权益（主）   余额     可用资金       资金占用       持仓盈亏  │
├──────────────────────────────────────────┬──────────────────┤
│ 货币对   模拟 M1   折线 / K 线  新练习    │ 交易金额（USD）  │
│ Bid / Ask / 点差                         │ 快捷金额 / 输入  │
│ 图表时间 / 价格读数                      │ 资金占用         │
│                 主图表                   │ 买涨 Ask 买跌 Bid│
│                                          │                  │
│                                          │ 方向 / 成交价    │
│ 播放 / 暂停 / 下一根 / 速度 / 可见进度     │ 当前盈亏 / 平仓  │
├──────────────────────────────────────────┴──────────────────┤
│ 成交记录                                                     │
│ 方向  金额  开仓价及时间  平仓价及时间  盈亏  平仓原因         │
└─────────────────────────────────────────────────────────────┘
```

工作台最大宽度 1520px，桌面外围间距 24px，下单区宽 336px，其余主要空间留给图表。品牌栏、账户指标横栏、主图与交易侧栏、成交区共用边距与对齐线，组成连续工作台。整体容器圆角 12px、无悬浮阴影，内部以细分隔线连接；1440×900 首屏容纳账户、报价、图表、回放及持仓平仓。品牌栏提供成交记录锚点和固定位置的本机保存状态。权益、Bid 和持仓盈亏有明确主次，数字与 USD 单位分级，不重复展示整组报价或完整行情时间。

宽度不超过 1100px 时，图表全宽，下方下单与持仓并排；不超过 600px 时改为单列，左右间距 16px。账户概要按实际容器宽度与 rem 重排：空间不足时权益占首行、其他指标两列，极窄或文字放大时单列，资金数字不会因平均分栏而拆行。行情与回放控件按功能自然换行，整页不横向溢出。图表下方提供“去下单 / 查看持仓与平仓”入口，主动点击后定位并聚焦金额或持仓标题；行情推进不抢焦点。

成交记录采用六列语义表格：方向、金额、开仓信息、平仓信息、结算盈亏、原因，开平仓的价格与时间分两行。宽度不超过 700px 时切换为可展开列表，摘要显示方向、名义金额和盈亏，详情保留所有报价、时间及原因。平仓入口保持在持仓区。

行情工具栏以品种标识、货币对和模拟状态说明当前内容，折线/K 线使用分段控件，“新练习”为次要操作。金额输入带 USD 后缀，快捷金额显示选中态；买涨与买跌使用浅语义底色，显示方向及各自成交报价。持仓区以盈亏及细语义边线为重点，开仓价、资金占用和开仓时间使用紧凑键值排版；墨色平仓按钮同时显示实际 Bid/Ask 平仓报价。已有持仓时明确说明禁用下单的原因。

P1 切换品种或“新练习”先暂停并保存旧练习，创建独立资金和新随机序列；旧记录保留，但尚无列表入口。P2–P3 的练习记录、数据管理和帮助计划使用次要面板，开启后有标题、关闭入口和焦点管理；导入、完整备份及清空不占常驻图表空间。

## 视觉与图表

- 背景 `#F3F4F6`、白色主区域、辅助表面 `#F7F8FA`、主文字与品牌墨色 `#18212E`、辅助文字 `#667085`；分隔线 `#E4E7EC`，必要控件边界 `#8490A2`。品牌蓝 `#325DEB` / 浅底 `#EDF2FF`，Bid 线 `#4267DF` 配纯色浅面积；盈利青绿 `#11765D` / `#EAF5F0`，亏损陶红 `#B4484D` / `#FFF0EF`。间距使用 4px 基数，控件圆角 6–8px。图标采用项目内 SVG。
- Inter 的英文及数字字体随应用打包，中文使用系统字体，金额及报价使用等宽数字。桌面 Bid 44px、Ask 24px，手机分别为 36px、20px；权益 32px、其他账户数字 20px、持仓盈亏 32px。正文及操作标签 14–16px，次要时间与单位 13px；实际字号用 rem。Bid 尾部两位固定为品牌蓝，仅表达精度层次。
- 金额带币种，报价使用一致精度；盈亏同时显示正负号、文字和颜色。方向按钮写“买涨（做多）”“买跌（做空）”。
- 控件颜色过渡 140ms，按下缩放 0.985、80ms；帮助淡入 140ms、最多位移 4px，交易反馈淡入 160ms。仅逐根推进的只读进度使用 100ms 宽度过渡，重置和恢复立即定位。焦点使用 2px 实色蓝环；`prefers-reduced-motion` 下取消过渡、位移及缩放。统一缓动为 `cubic-bezier(.2,.8,.2,1)`。报价、账户和图表即时更新，不滚动数字或持续闪烁。
- 默认打开暂停的模拟练习，默认 Bid 折线；切换 K 线时提供简短 OHLC 解释。货币对和交易数值默认值由 [数据与交易](03-data-and-trading.md) 维护。
- Apache ECharts 负责 Bid 折线与 K 线。十字线显示已可见的时间及价格；缩放和平移只能访问已经推进的数据，提供回到最新入口。报价、行情时间、图表和账户同步更新。
- 图表画布桌面高 350px、手机高 300px，均以 rem 定义。轴标签沿用正文缩放后的字体，时间标签数量按可用宽度减少。最新价只在最新帧处于观察范围时显示，使用右侧蓝色标签；按像素距离隐藏碰撞的普通价格刻度，观察旧区域时不展示范围外当前价。
- 开仓水平线使用实际成交报价，开平仓标记显示方向与成交价。买涨的 Ask 入场线可以高于 Bid 曲线，不能为了贴合曲线改写成交价。
- 首根行情居中呈现，并说明初始状态，不填入虚构走势或未来占位行情。用户缩放或平移后的观察范围保持稳定；只有原来跟随最新时才自动移动。
- 页面不展示图表库品牌、版权段落、裸链接或技术页脚。依赖许可和 NOTICE 随源码及构建产物提供，不通过隐藏原图表库所要求的署名实现页面清理；选型依据见 [网页工程](../knowledge/02-web-engineering.md#图表与十进制计算)。

## 状态、错误与操作反馈

模拟、交易和保存场景已接入 P1；历史、导入、完整备份及清空场景为后续阶段的交互标准。

| 场景 | 页面行为 |
| --- | --- |
| 首次进入 | 加载时使用与工作台一致的状态区域；完成后暂停行情，显示首根报价、模拟来源及交易操作；三步引导仍为 P3 |
| 无持仓或无成交 | 保持交易区和记录区的结构，使用简短状态、必要入口与轻量图标，避免大块教学文字 |
| 无历史样本 | 说明如何准备或导入数据，保留进入模拟练习的入口 |
| 交易金额无效或资金不足 | 在输入附近给出原因并保留输入；不能下单时提供可读说明 |
| 开仓后出现浮亏 | 在对应信息提示中解释买卖报价差形成点差成本，不暗示系统扣除了额外费用 |
| 开仓或平仓完成 | 保存成功后短反馈；开仓聚焦持仓标题，平仓聚焦金额，屏幕外的目标就近滚入；反馈中结算盈亏按实际正负着色，账户、记录和成交标记同步更新 |
| 行情数据结束 | 停止播放、标明结束，按最后可见报价提供平仓操作 |
| 切换行情或恢复会话 | 按会话规则保存与装载，恢复后显示暂停状态 |
| 导入或恢复失败 | 显示具体原因；CSV 能定位时给出行号，保留原有数据 |
| 保存失败 | 显示“保存失败”并暂停推进与交易，提供重试、导出当前快照入口；由开平仓触发的写入失败将焦点移至持续错误区 |
| 多窗口保存冲突 | 拒绝陈旧写入，保留当前窗口快照；提示导出后重新打开最新练习 |
| 覆盖或清空记录 | 写明数据范围，由用户明确选择；取消操作保留已有记录 |

保存状态保留在品牌栏固定位置。金额错误、保存失败和多窗口冲突持续显示具体原因及恢复入口，不收进帮助提示。普通下单与平仓无需增加重复确认。恢复、导入和保存中的按钮状态清楚，重复点击不产生重复成交或重复写入。

## 新手帮助与可访问性

P1 在报价、交易金额、点差、资金占用及 K 线操作附近提供可点击的信息提示，平时只显示相关标签与信息按钮。提示支持键盘开启；按 Escape 或关闭按钮收起并返回触发按钮，点击外部或焦点离开时收起并保留用户的新焦点。必要错误和恢复操作保持可见。P3 首用引导计划控制为三步：认识 Bid/Ask 与走势图、开仓观察点差、推进行情后平仓查看结果。每步指向当前控件并可跳过，不要求先完成课程。

控件使用语义化按钮、标签和输入框，键盘可操作，并保留清楚可见的焦点。面板关闭后焦点回到开启入口；错误与保存结果使用可读状态提示。图表之外始终显示当前报价和持仓数字，不把交易必需信息只放在画布中。

文字和交互对比度参照 WCAG 2.2 定向检查；页面支持 200% 文字放大，320–1440px 的六种验收宽度无整页横向溢出。手机主要按钮、选择与帮助触控区至少 44px；键盘焦点与错误持续可见。工程资料见 [前端与存储知识](../knowledge/02-web-engineering.md)，实际验证及系统性无障碍检查的限制只记录到 [路线与验收](04-roadmap-and-acceptance.md)。
