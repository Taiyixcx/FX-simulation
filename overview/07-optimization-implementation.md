## 参数版本与数据研究

估计普通收益时只采用相邻完整分钟的同步 Bid/Ask 中间价，排除时间缺口；按照现有季节性模型归一，再将稳健尺度与原参数参考模拟相匹配。点差基准匹配源样本中位数并保留原最小训练点差。样本来自单一供应商，不能推导全部经纪商的报价、真实逐笔执行或未来表现。

参数数值及规范定义只在 [数据与交易](03-data-and-trading.md#模拟行情) 维护；机器可读数值与月份指纹在 [冻结参数资料](../public/data/simulation-calibration.json)。版本 1 继续使用原表；已有版本 1 会话恢复不自动切换参数，schema2 衔接保留其参数版本。旧引擎与当前显式参数 1 的两品种×两情景×3,000 根完整行情及源状态严格一致，覆盖周末和美国夏令时切换。事件频率、影响、波动持续和季节形状没有据此宣称完成校准。

9 月留出中，去季节化稳健尺度相对误差：EUR/USD 从 25.8% 降至 6.1%，GBP/USD 从 21.6% 降至 10.4%；点差中位数相对误差分别由 400% 降至 50%、75% 降至 12.5%。小点差的相对误差会放大差异，不能只用这些数值评价整体模型；完整指标在 `.vite/calibration-validation.json`，可用 `npm run check:calibration` 复核。

GBP/USD 2024-10 原 tick 在第 1,799,990 行倒序，转换器已拒绝，未排序或删行；EUR/USD 2024-10 已用于探索，因此不计未见留出。原 ZIP、tick 与月度 CSV 只在 `local-data/`，不随 Git 提交。研究文件需本人按 [HistData 格式](https://www.histdata.com/f-a-q/data-files-detailed-specification/) 和 [个人测试用途说明](https://www.histdata.com/about-us/) 准备，免费取得不推导公开价格再分发许可。

## 浏览器性能与容量

环境为 Windows `10.0.26300`、i7-13700H、约 29.7 GiB 内存、Chromium `153.0.8010.12`。均用独立浏览器资料和生成 CSV，不写本人数据库；单次测量不是分位数或硬件通用保证。

同一 Chromium、同一生成文件、顺序运行旧 `9bc89a3` 和当前解析模块，覆盖解析、验证及 SHA-256，不含文件选择、IndexedDB 或整个页面导入。7,000／50,000／200,000 根的旧解析耗时为 76／444／1,703ms，当前为 76／459／1,835ms；计时器最大间隔由 78／444／1,703ms 降为 12／15／65ms。三种规模的规范化指纹完全一致。此结果说明减少连续阻塞，不能描述为总解析更快。中间采用零延时定时器的方案曾耗时约 18 秒，已由实际复测发现并替换。

最终完整生产回归中，7,000／50,000／200,000 根页面导入约 0.43／1.56／4.58 秒，冷恢复约 0.25／0.48／1.69 秒，导入期间切 K 线为 94／90／78ms；最大 long task 为 0／53／283ms。启用 Chromium 精确内存信息后，25ms 采样的 JS heap 峰值约 29／82／345 MiB，基线约 9 MiB；不是整个进程或系统内存峰值。20 万根文件为 9,600,033 字节，内存放大依然明显。取消实测约 94ms，原会话保持且数据集数为零；修正了进度文字导致取消按钮移动的问题。

两个数据集合计 57,000 根、0／500 笔闭单的原生 IndexedDB 流程通过；最终列表约 58／76ms、推进并保存约 68／159ms、冷恢复约 232／520ms、完整备份约 0.75／1.02 秒、验证并追加打开约 1.99／2.12 秒。文件约 9.5／9.6 MiB；账户、成交和下一行情位置与备份前一致。构造夹具耗时不计入业务计时，保存计时包含校验与事务完成，未拆分纯存储提交耗时；恢复包含文件校验、预览及用户选择操作。归档定位功能已验证，未给出独立的归档读取性能分位数。

128 MiB 是拒绝超大备份的输入预算，不是已实测该大小一定能成功；本轮完整备份实际规模约 10 MB。整文件 JSON 和完整源验证仍有内存与冷恢复成本，浏览器配额、系统内存及存储清理会影响结果。JS heap 若可取得只作为近似值，不当作整个浏览器进程的内存峰值。完整最终页面测量保存在 `.vite/browser-performance-*.json`、`.vite/library-performance-*.json` 和 `.vite/browser-cancellation.json`。
