# 产品与设计

## 定位与使用流程

FX 练习室是供本人在本机使用的外汇练习站。通过生成行情和真实历史报价，练习观察走势、判断方向、开仓、平仓和复盘。界面面向新手，优先保证图表清楚、操作直接和交易结果容易理解。

主要流程为“选择行情与品种 → 查看报价 → 输入金额 → 买涨或买跌 → 推进行情 → 平仓并查看记录”。固定种子和历史回放支持重复练习；本地保存支持中断后继续。

真实历史报价与训练成交模型分别标识。分钟回放呈现已经完成的分钟数据，不声称还原逐笔执行。具体默认参数、交易计算和会话规则统一见 [数据与交易](03-data-and-trading.md)，实施顺序和检查场景见 [路线与验收](04-roadmap-and-acceptance.md)。

## 首版范围

| 能力 | 交付行为 |
| --- | --- |
| 工作台 | 一个页面承载账户、行情、下单、持仓和成交记录 |
| 行情 | EUR/USD、GBP/USD；支持可复现的离线模拟与真实分钟历史回放 |
| 数据 | 选择已准备的本机样本，按统一 CSV 模板导入个人文件 |
| 图表 | Bid 折线与 K 线切换、十字线、缩放、开平仓标记 |
| 回放 | 播放、暂停、推进下一根和调速；所有交易使用同一可见进度 |
| 交易 | 买涨、买跌和手动平仓，显示实际成交报价与资金占用 |
| 账户 | 区分余额、权益、可用资金和持仓盈亏 |
| 复盘 | 自动记录成交，支持纯文本备注和会话查看 |
| 本地数据 | 保存一致快照，提供备份导出与校验后的恢复 |
| 帮助 | 可跳过的三步首用引导和操作旁术语解释 |

首版采用单页纯前端应用，无登录、后端、云同步、实时行情接口或真实下单。可调杠杆、多仓、挂单、止盈止损、滑点、隔夜费、完整经纪商保证金模型、技术指标和复杂报表，待实际使用后另行评估。排行榜、社区、贷款和挑战不纳入当前产品。

界面借鉴图表主导的回放操作、自动交易记录和操作旁教学，产品资料及取舍依据集中在 [同类作品研究](../knowledge/03-product-references.md)。

## 工作台布局

```text
┌─────────────────────────────────────────────────────────────┐
│ FX 练习室  模拟行情 / 历史回放         练习记录 数据管理 帮助 │
├─────────────────────────────────────────────────────────────┤
│ 余额           权益           可用资金    持仓盈亏    保存状态 │
├──────────────────────────────────────────┬──────────────────┤
│ 货币对   数据来源   行情时间              │ 交易金额         │
│ Bid / Ask / 点差                         │ 快捷金额 / 输入  │
│                                          │ 资金占用 / 报价  │
│                 主图表                   │ 买涨     买跌    │
│                                          │                  │
│                                          │ 方向 / 成交价    │
│ 播放 / 暂停 / 下一根 / 速度  折线 / K 线  │ 当前盈亏 / 平仓  │
├──────────────────────────────────────────┴──────────────────┤
│ 当前持仓 / 成交记录                                          │
│ 方向  金额  开仓价  平仓价  盈亏  时间  备注                   │
└─────────────────────────────────────────────────────────────┘
```

桌面下单区宽约 300px，其余主要空间留给图表。账户使用对齐的文字和数字；各区域以留白、细分隔线和一致的边距连接，保持连续工作台。

小于 960px 时改为“账户与报价 → 图表及回放 → 下单与持仓 → 成交记录”的纵向排列。操作栏可以换行，成交表格仅在自己的区域横向滚动，整页不横向溢出。平仓入口同时出现在下单区持仓摘要中，窄屏无需翻到成交记录寻找。

练习记录、数据管理和帮助使用次要面板。面板开启后有明确标题、关闭入口和焦点管理；导入、备份及清空记录不占常驻图表空间。

## 视觉与图表

- 冷白背景、深灰正文、克制蓝色主操作；正文以 16px 为主，常用标签至少 14px。使用系统中文字体和等宽数字。
- 金额带币种，报价使用一致精度；盈亏同时显示正负号、文字和颜色。方向按钮写“买涨（做多）”“买跌（做空）”。
- 避免卡片堆叠、大圆角、悬浮阴影、装饰渐变、宣传首页和庆祝动效。文案直接解释报价、交易与结果。
- 默认打开暂停的模拟练习，默认 Bid 折线；切换 K 线时提供简短 OHLC 解释。货币对和交易数值默认值由 [数据与交易](03-data-and-trading.md) 维护。
- 十字线显示已可见的时间及价格；缩放只能访问已经推进的数据。报价、行情时间、图表和账户同步更新。
- 开仓水平线使用实际成交报价，开平仓标记显示方向与成交价。买涨的 Ask 入场线可以高于 Bid 曲线，不能为了贴合曲线改写成交价。
- 图表角落保留 Lightweight Charts 要求的署名，不用遮盖报价或交易操作的浮层承载。

## 状态、错误与操作反馈

| 场景 | 页面行为 |
| --- | --- |
| 首次进入 | 暂停行情，显示报价、来源和可用交易操作；可选择开始引导 |
| 无历史样本 | 说明如何准备或导入数据，保留进入模拟练习的入口 |
| 交易金额无效或资金不足 | 在输入附近给出原因并保留输入；不能下单时提供可读说明 |
| 开仓后出现浮亏 | 就地解释买卖报价差形成点差成本，不暗示系统扣除了额外费用 |
| 平仓完成 | 更新账户与记录，保留图表标记，用简短状态文字反馈 |
| 历史数据结束 | 停止播放、标明结束，按最后可见报价提供平仓操作 |
| 切换行情或恢复会话 | 按会话规则保存与装载，恢复后显示暂停状态 |
| 导入或恢复失败 | 显示具体原因；CSV 能定位时给出行号，保留原有数据 |
| 保存失败 | 显示“保存失败”并暂停推进与交易，提供重试、导出当前快照入口 |
| 覆盖或清空记录 | 写明数据范围，由用户明确选择；取消操作保留已有记录 |

普通下单与平仓无需增加重复确认。恢复、导入和保存中的按钮状态清楚，重复点击不产生重复成交或重复写入。

## 新手帮助与可访问性

首用引导控制为三步：认识 Bid/Ask 与走势图、开仓观察点差、推进行情后平仓查看结果。每步就地指向当前控件，始终可跳过；用户可从帮助入口重新查看。点差、权益、可用资金和 K 线解释放在对应操作附近，不要求先完成课程。

控件使用语义化按钮、标签和输入框，键盘可操作，并保留清楚可见的焦点。面板关闭后焦点回到开启入口；错误与保存结果使用可读状态提示。图表之外始终显示当前报价和持仓数字，不把交易必需信息只放在画布中。

文字和交互对比度参照 WCAG 2.2 定向检查；页面支持 200% 文字放大，1440px、1024px 和 390px 宽度仍能完成交易。控制区避免持续闪烁，尊重减少动态效果的系统设置。工程资料见 [前端与存储知识](../knowledge/02-web-engineering.md)，实际验证结果只记录到 [路线与验收](04-roadmap-and-acceptance.md)。
